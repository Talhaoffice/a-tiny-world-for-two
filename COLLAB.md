type PetKind = 'none' | 'cat' | 'fox'
type PetRecord = { kind: PetKind; name: string; updatedAt: serverTimestamp }

## Handoff — cuddle sync follow-up (2026-10-30)

- **Data flow verified in source:** `HomeInterior.setSleeping()` calls `onSleepChange`; `WorldGame` writes the local coordinates and `position.anim` to `world/players/{uid}/position` through `connectWorldSync.publishPosition()`. The same `world/players` listener reads `player.position.anim`, filters the peer by online presence and the current `home` zone, and passes `RemotePosition` to `WorldGame` state. React rerenders `HomeInterior` when that state changes. `avatarStyle()` maps cottage room coordinates to the same `.home-room` percentage space that contains the bed.
- **Root cause:** sleep was encoded in optional `position.anim`, while `publishPosition()` rebuilt the whole position record and omitted `anim` for ordinary position-only updates. The listener then exposed `anim: undefined`, and `HomeInterior` treated that as awake; this could make the two sessions disagree and suppress the cuddle even after observing sleep. This has been corrected by retaining `sleep` through position-only publications until an explicit wake animation (`idle`) arrives. The cottage also retains a received sleep state across legacy/position-only remote snapshots, but immediately clears it on explicit wake or missing/disconnected remote state. Cuddle layout now comes from stable character IDs in the cottage view and ignores overworld movement coordinates while both sleep.
